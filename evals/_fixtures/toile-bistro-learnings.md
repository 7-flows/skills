# Toile — office workers order the lunch set

## Assumption
Office workers nearby will order a $25 two-course lunch set.

## Risk
Medium — it sets how much the kitchen preps for weekday lunch.

## Evidence so far
Regulars ask for something quicker than the menu. No set has been offered.

## Test design
The set on the board for two weeks of lunch service; about 150 lunch customers; count set orders.

## Pass line
20% of lunch customers order the set — 30 of 150.

## Time box
10 lunch services.

## Results
41 of 150 ordered the set (27%). Three asked for it without dessert.

## Learnings
Clears the line beyond chance: the close-call check put the pass mark at 39. Dessert is not what sells it.
